# 说说岛 · Sayland

给小朋友的体素创作小岛。通过文字或短句录音告诉伙伴想搭什么，DeepSeek 生成受限场景指令，Three.js 显示真实可编辑的方块。首版为本机单用户原型，UI 与独立后端已实现，尚待用户体验验收。

## 运行

```sh
npm ci --ignore-scripts
cp .env.example .env.local # 仅首次配置；已有配置时不要覆盖
chmod 600 .env.local
npm run dev
```

在 `.env.local` 填写服务端凭据后，打开 <http://127.0.0.1:4310>。API 监听 `127.0.0.1:4311`，Vite 代理 `/api`。当前开发机已按用户授权配置，无需重复复制。`Ctrl-C` 同时关闭前后端；更改后端代码或配置后需重启。

使用 Node.js 22.13+；本次在 Node 23.10.0 / npm 10.9.2 验证。依赖以 `package-lock.json` 为准。

```sh
npm test          # 纯本地契约/内核/网络边界测试，不调用付费模型
npm run typecheck
npm run build    # dist/web + dist/api/server.mjs
```

## 可以试什么

- “把小房子的屋顶变成蓝色，其他地方都不要改变。”
- “在小房子旁边种一棵大树。”
- 在左侧选颜色涂方块，或选方块工具后点击已有方块的表面添加。
- 撤销一次完整对话；设置中可重做、导出、导入或恢复初始小岛。
- 按住空格键或屏幕上的伙伴录音，松开发送；输入框里的空格照常打字。Esc、切出窗口或触控中断取消且不发送，AI 追问后也须再次按住。识别仍使用小米 ASR，完成后搭建并朗读，无实时字幕。单次最多 120 秒，超限取消并提示，不自动发送截断录音。

根地址 `/` 是项目首页；进入或新建项目后，地址变为 `/projects/<场景ID>`，刷新或直接打开该地址会恢复对应项目，不会回首页。新建可选空白场景或默认小岛。编辑器右上角“返回项目首页”退出当前项目，新建仅在首页提供。浏览器前进／后退同样遵守退出保存检查。每个场景独立保存作品、对话与任务；不同场景最多4项任务并行，同一场景按顺序排队，搭建期间可以继续输入下一个想法。

首页项目卡右上角可删除项目，确认后清理作品、对话、草稿、缩略图和任务记录，并停止该项目正在运行与排队的 AI 任务；操作无法恢复，其他项目不受影响。

无需手动保存。每5秒检查未保存改动，内容没变不重复提交；AI实际搭建的每批结果仍即时保存在后台。编辑器显示“保存中／已自动保存／保存失败”，失败可重试；有未保存内容时，退出会提示“保存并退出／不保存退出／取消”。正常退出保存当前场景渲染图作为项目封面；选择不保存保留上次缩略图，已经自动保存的模型不会回退。保存失败时保留当前项目，可重试。场景和任务自动保存在本机后端 `.sayland/workspace.sqlite`。关闭网页仍继续搭建，重开恢复结果；必须保持电脑唤醒且后端运行。后端停止或重启会标记中断并保留已完成部分，不自动重放模型调用。第一次打开会复制迁入旧 IndexedDB 作品，原备份保留。

导出 `.sayland.json` 仍包含当前场景、历史与对话，不含密钥。没有账户或跨设备云同步；备份全部数据可先正常停止服务，再复制完整 `.sayland` 目录。实现和恢复约定见 [后台工作区说明](apps/api/WORKSPACE.md)。

## 导出 3D 打印与建模文件

设置 →「导出 3D 模型」，选择全部场景或勾选物件/部件，设置每格毫米尺寸后下载 ZIP。包内包含 3MF、FBX、材质清单、原始快照和贴图；所选部件保持相对位置，整体底部归零。

解压后将 `model.3mf` 导入 Bambu Studio，选择你的机型、耗材和支撑，映射颜色后切片并检查逐层预览。颜色不会自动对应实际耗材，屏幕光影也不会变成打印材质；包内附有悬空/分离检查结果。FBX 保留数字模型的颜色、贴图与物件层级，可继续编辑。尚未进行真实拓竹打印验收，具体格式与限制见[导出说明](apps/web/src/export/README.md)。

## 分组与隐藏调试

新生成物件按“物件组 → 部件”组织，例如机器人下的身体、眼睛、手脚。整组可移动、改色或删除，也能只调整某个部件；操作保留稳定编号并支持撤销、重做和自动保存。旧作品照常读取，未分组部件保留原状与历史，不根据名称猜分组。

开发时按 `Cmd/Ctrl + Shift + D`，或在页面地址添加 `?debug=1` 打开隐藏调试面板。面板提供分组树、统计、选中框及移动、改色、归组、新建组、改名、删除、撤销和重做；关闭后清除选中框。编辑仍走同一个场景内核，忙碌时禁止修改。

面板展示当前场景最近5个创作回合，手动读取后台已保存的任务诊断；关闭面板或切换回合会取消在途读取，诊断展示遮挡secret类字段。回合诊断不写入作品导出文件。桌面编辑与390×844窄屏交互已做隔离浏览器检查，真实设备体验仍待验收；实现与验证边界见 [PROJECT_MAP.md](PROJECT_MAP.md)。

## 首版边界

- React + Three.js 前端、Fastify 后端。密钥只在服务端，不经过浏览器；没有账户、云同步或公网部署。
- 语音是真实小米 MiMo ASR/TTS；后端短句音频调用已验证，真实麦克风、浏览器权限和扬声器体验需在用户设备验收。
- 自由造型不限定物件种类。模型可查询真实占位，在隔离副本预演并根据错误修正；通过后才提交完整计划并播报成功。仍未完成的计划会保留原场景，造型质量需要实际体验。
- 默认草地 112×80、水域 144×128；初始 116,690 方块，场景上限 500,000 方块，仍余约 38 万块可创作；这是资源保护值，非设备帧率承诺。已检查桌面、平板和手机的浏览器布局，未完成移动设备性能验收。
- 本机场景库由当前电脑共享，session 不是公开网站的账户鉴权；当前服务不应直接暴露公网。
